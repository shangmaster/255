拍照签到（本地图片）

只做一件事：把本地图片提交为学习通的拍照签到。

一、基本设置

先看页面自己的请求，再查这门课的活动列表（每 30 秒重试，拿到就停）
只打印将要发送的参数，不真正提交
默认 15（网页端），一般不用改

二、连通性自检

未检测
「检查登录状态」确认浏览器已登录学习通；「检查图片上传通道」确认能拿到网盘上传令牌 （拍照签到要先把图片传上去换 objectId）。

三、它是怎么工作的

1. 面板自动获取这次活动的 activeId（课程活动列表接口，只取"进行中"的）；
2. 你选一张本地图片 → 校验格式与大小 → 上传到学习通网盘换回 objectId；
3. 用极简参数 + GET 提交 pptSign/stuSignajax：
   activeId / uid / clientip / latitude(-1) / longitude(-1) / appType / fid / objectId / name
4. 服务端返回 success 就是签到成功。

注意：如果服务端返回 photoAuthError_*，说明这次活动开了拍照校验 （要求本机现场拍摄的凭证），网页端拿不到 —— 学习通自己的网页在这种活动上也是直接提示 "请使用手机APP"，只能用 APP 完成。
