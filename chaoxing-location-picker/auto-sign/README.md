# 完全自动签到（不需要开浏览器）

这个目录是**独立程序**，不依赖上面的浏览器扩展。装好之后：

- 开机 / 登录 Windows 就自动运行；
- 每 1 分钟检查一次课程活动，只在你自己设定的时段里真正发请求；
- 发现**位置签到**就自动完成，离签到地点太远会自己算坐标逼近，直到签上；
- 识别出普通 / 二维码 / 签到码 / 手势 / 人脸，**只记日志，不动手**；
- 全程无窗口、无弹窗、不需要你点任何东西。

> 为什么不用扩展做？Chrome / Edge 的 MV3 扩展**没有办法在后台主动打开网页**，
> 也没法在页面没打开时拿到页面上下文。要做到"开机就自己签到"，必须是一个
> 独立进程直接调接口 —— 就是这里这套。

---

## 一、三种启动方式，选一个

| 方式 | 命令 | 什么时候用 |
| --- | --- | --- |
| **计划任务（推荐）** | `run.bat install` 或 `python sign.py --install` | 真正的"开机即自动"，装一次以后再也不用管 |
| 常驻进程 | `run.bat daemon` 或 `python sign.py --daemon` | 不想注册计划任务，关掉窗口就停 |
| 单次 | `python sign.py --once` | 手测 / 临时签一次 |

计划任务用的是 `pythonw.exe`，**没有黑窗口**，也不需要管理员权限。

## 二、第一次配置（4 步，约 3 分钟）

### 第 1 步：导出登录态

打开 `export-cookies.html`，按页面上写的步骤做。要点：

1. 先在浏览器里登录 [i.chaoxing.com](https://i.chaoxing.com/base)；
2. `F12` → **Application / 应用** → **Cookies** → 选 `https://i.chaoxing.com`；
3. 把 `_uid`、`UID`、`fid`、`_d`、`uf`、`jrose`、`route`、`JSESSIONID` 这几个抄到页面里；
4. 点「生成 cookies.json」→「下载」→ 放到本目录，覆盖同名文件。

> `_uid` 是 HttpOnly 的，`document.cookie` 读不到，必须从 Application 面板里抄。

文件长这样就行：

```json
{
  "cookies": {
    "_uid": "123456789",
    "UID": "123456789",
    "fid": "1234",
    "_d": "xxxxxxxx",
    "uf": "xxxxxxxx",
    "jrose": "xxxxxxxx",
    "route": "xxxxxxxx"
  }
}
```

验证一下：

```
python sign.py --verify
```

看到 `✓ cookie 可用` 就成了。

### 第 2 步：抓课程清单

```
python sign.py --list-courses
```

它会从课表接口取出你所有课程，写进 `config.json` 的 `courses`：

```json
"courses": [
  { "name": "高等数学 / 2024级1班", "course_id": "268194985", "class_id": "157462133" }
]
```

自动签到每分钟都会遍历这份清单去找"进行中"的签到，所以**想监控哪门课，就把它留在清单里**。
只留需要签到的课可以加快查询、少打扰服务端。

### 第 3 步：填起始坐标

随便填一个**大概位置**就行 —— 差得远也没关系，程序会自己用"距离还差多少米"
一点点逼近真实签到点。

```
python sign.py --set point=38.0412,114.5123
```

或者直接改 `config.json`：

```json
"start_point": { "lat": 38.0412, "lon": 114.5123, "address": "XX大学" }
```

> 坐标用 GCJ-02（高德/腾讯地图的坐标系）。在地图上右键"这是哪儿"抄经纬度即可。
> `address` 只是显示给老师看的文本，随便写。

### 第 4 步：装计划任务

```
python sign.py --install
```

然后验证一次：

```
python sign.py --status
```

看到 `下次开门 : 2026-10-26 07:30` 这类内容就说明一切就绪。

## 三、改时段 / 改星期

默认是 **周一至周五 08:00-14:00**。

```bash
python sign.py --set start_time=07:30 --set end_time=13:30
python sign.py --set weekdays=[1,2,3,4,5]      # 1=周一 … 6=周六 0=周日，[] = 每天都跑
```

或者直接改 `config.json`：

```json
{
  "enabled": true,
  "start_time": "07:30",
  "end_time": "13:30",
  "weekdays": [1, 2, 3, 4, 5]
}
```

支持跨夜（`"start_time": "22:00", "end_time": "02:00"`）。

## 四、它到底怎么签到

```
每分钟（计划任务）
   └─ 现在在时段内吗？不在就退出（一行日志都不写，开销≈0）
        └─ 今天已经签过了吗？签过就退出
             └─ 遍历课程清单 → GET activelist 找"进行中"
                  ├─ 只有普通/二维码/手势/签到码 → 写一条日志，不做任何事
                  └─ 有位置签到 → 提交坐标
                       ├─ success → 记住这个点，今天收工
                       └─ "距离签到地点还有 1568 米"
                            ├─ 把这句当一次"距离测量"
                            ├─ 换个方向再提交 → 第二个圆
                            ├─ 再换方向 → 第三个圆 → 三点定位算出签到点
                            └─ 在算出的点附近细调，直到 success
```

会自己停手的情况（不会无限刷服务端）：

- 要人脸 / 要二维码 → 接口方式拿不到凭证，只能 APP；
- 活动已结束 / 登录失效；
- 已经在范围边上（只差 0~1 米）却还被拒 → 判定不是距离问题；
- 单次超过 `max_rounds`（默认 10 次）；
- 当天累计找了 `max_minutes_per_day`（默认 180 分钟）。

## 六、常见问题

| 现象 | 处理 |
| --- | --- |
| 日志写「没有 cookies.json」 | 先做第二步，把导出的文件放进本目录 |
| 日志写「登录态失效」 | cookie 过期了，回 `export-cookies.html` 重新导一次 |
| 日志写「config.json 里没有课程清单」 | 跑 `python sign.py --list-courses` |
| 日志写「读不到 uid」 | cookie 里没有 `_uid`，在 `config.json` 里手填 `"uid": "你的uid"` |
| 一直显示「没有进行中的签到」 | 老师还没发，或者你监控的课不对（看 `courses`） |
| 一直「只差 X 米」还签不上 | 老师把范围设得特别小，或有设备校验；先手动把 `start_point` 设到真实地点试试 |
| 装了计划任务但一天没动静 | `python sign.py --status` 看「下次开门」；确认电脑在那个时段是开着的（睡眠/关机期间没法跑） |
| 想卸载 | `python sign.py --uninstall` |

**电脑必须处于开机状态**。休眠会暂停计划任务；笔记本合盖的时段它不会跑。
如果你需要在合盖时段签到，把电源计划里"合盖不睡眠"打开，或用 `--daemon` 挂在一个不关的终端里。

## 七、文件说明

```
auto-sign/
├── core.py               协议 + 三点定位 + 逼近循环（纯逻辑，可脱网测试）
├── sign.py               主程序（配置、cookie、计划任务、日志）
├── run.bat               双击即用的入口（纯 ASCII，兼容各种 cmd 编码）
├── export-cookies.html   在浏览器里导出登录态并生成 cookies.json
├── tests/test_core.py    50 项脱网单测
├── config.json           ← 你的配置（自动生成）
├── cookies.json          ← 你的登录态
├── state.json            今天的进度
└── logs/                 日志
```

跑测试：

```bash
python -m unittest discover -s tests -t .
```

---

## 八、边界

- cookie 只存在你自己电脑上，程序只访问 `chaoxing.com` 的接口，不发往任何第三方。
- 服务端如果加上"必须原生 APP 上报位置/设备指纹"这类校验，任何网页/脚本方案都会失效。
- 签到是考勤行为，只用在你自己的账号上。
